radamsa

Description​

  • Radamsa is a general-purpose data fuzzer.
    • Reads data from the specified sample file or standard input if none exists, and outputs modified data.
    • It is commonly used to generate manipulated data for program testing.
    • Supported OSs include GNU/Linux, OpenBSD, FreeBSD, Mac OS X, and Windows (using Cygwin).

Install​

Install radamsa
$ git clone https://github.com/aoh/radamsa.git ~/radamasa/
$ cd radamsa
$ make
$ sudo make install # optional, you can also just grab bin/radamsa
$ radamsa --help

Command options​

OptionsDescription
-o--output , output pattern
-n--count , number of outputs to generate
-s--seed , random seed (number, default random)
-m--mutations , Mutations to use [ft=2,fo=2,fn,num=5,td,tr2,ts1,tr,ts2,ld,lds,lr2,li,ls,lp,lr,lis,lrs,sr,sd,bd,bf,bi,br,bp,bei,bed,ber,uw,ui=2,xp=9,ab]
-p--patterns , mutation pattern to use [od,nd=2,bu]
-g--generators , data generator to use [random,file=1000,jump=200,stdin=100000]
-M--meta , store metadata about the generated file in this file
-r--recursive, include files in subdirectories
-S--seek , start with the given test case.
-d--delay , wait n milliseconds between outputs
-l--list, list of mutations, patterns and generators
-C--checksums , maximum number of checksums in uniqueness filter (0 is disabled) [10000]
-v--verbose, display progress during creation

Options of Output​

-o argumentmeaningexample
:port* Acts as a TCP server on the designated port.# radamsa -o :80 -n inf samples/*.http-resp
ip:port* Connect to the IP and port of the TCP client.$ radamsa -o 127.0.0.1:80 -n inf samples/*.http-req
-* Print the results on the screen.$ radamsa -o - samples/*.vt100
path* Create the result as a file in the corresponding path. + %n: test case number + %s: first suffix$ radamsa -o test-%n.%s -n 100 samples/*.foo

Options of Mutations​

Options of mutationsDescription

bddrop one byte
bfflip 1 bit
biInsert random bytes
brrepeat one byte
bpchange some bytes
beiIncrement by one byte
bedDecrease by one byte
berReplace with a random byte
srByte sequence repetition
sdDelete byte sequence
lddelete one line
ldsDelete multiple lines
lr2single line replication
liCopy one nearby line
lrrepeat one line
lsreplace two lines
lpChange the order of lines
lisInsert a line somewhere else
lrsDating a Line Elsewhere
tddelete node
tr2node replication
ts1Swap one node for another
ts2swap two nodes
trRepeats the path in the parse tree.
uwTry to make the code section wider
uiInteresting unicode insertion
numAttempt to edit text number
xpParse and transform xml

File​

  • Here's how to create a modified ".png" file.
    • A png file is saved in “testcase”.
    • Save 100 transformed png files in the “sample” folder.
Create fuzz files

lazenca0x0@ubuntu:~/Documents/radamsa$ radamsa -r testcase/ -o sample/img-%n.png -n 100
