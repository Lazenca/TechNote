# **Canaries**

* A Canary or Canary word is a known value placed between a buffer and control data (such as return addresses or saved frame pointers) on the stack to monitor for buffer overflows.
* When a buffer overflow occurs, the canary value is overwritten and corrupted; validation of the canary fails at function return, triggering an error message and terminating the process immediately.

## **Types of canaries**

### **Terminator canaries**

* Terminator Canaries are constructed using characters that represent string terminators.
* Terminator Canaries consist of NULL (0x00), CR (0x0d), LF (0x0a), and EOF (0xff).
  + To overwrite the return address, an attacker would need to write a null byte before reaching the return address.
  + String manipulation functions like strcpy() terminate when encountering a null byte, preventing further overflow.
    - strcpy() stops copying upon reaching a null byte.
  + Despite this protection, attackers might still bypass it if non-string copy operations or specific input channels allow arbitrary byte writes.

### **Random canaries**

* Random Canaries are generated randomly when the program initializes.
  + Predicting or brute-forcing the canary value is computationally infeasible without an information leak.
* During program startup, the master canary value is stored in a thread-local storage / global segment (e.g., fs:0x28).
  + This reference value is stored in protected memory.
    - Unauthorized attempts to read unmapped or protected pages cause a segmentation fault.
  + If an attacker can leak memory from the stack (e.g., via format string vulnerabilities or out-of-bounds reads), the canary value can be obtained and reused in an exploit payload.

### Random XOR canaries

* Random XOR Canaries are created by XOR-scrambling the random canary with control data (such as the return address or frame pointer).
  + Under this scheme, if either the canary value or the control data is corrupted, the canary verification fails.
* Random XOR Canaries share similar vulnerabilities with standard Random Canaries.
  + Extracting and forging the canary on the stack requires extra steps.
  + The attacker needs the original canary value, the XOR algorithm, and the control data to reconstruct a valid canary.

## **Example**

### **Source code**

```c title="Canary.c"
#include <stdio.h>

void main(int argc, char **argv)
{
	char Overflow[32];
	
	printf("Hello world!\n");
	gets(Overflow);

}
```

### Build command

```bash title="Option"
gcc -fstack-protector --param ssp-buffer-size=N xx.c   ==> Change buffer size threshold (N bytes)
gcc -fstack-protector-all xx.c                         ==> Protect all functions
```

```bash title="Build Command(Do not set Canary)"
gcc -fstack-protector -o canary canary.c
```

## **How to detect Canary in the "Checksec.sh" file**

### Binary

* **Verify whether Canary protection is enabled in a binary using the following method:**
  + Inspect the symbol table of the file using readelf to verify canary protection.
  + If "__stack_chk_fail" is present in the symbol table, stack canary protection is considered enabled.

```bash title="Checksec.sh - line 156" 
  # check for stack canary support
  if readelf -s $1 2>/dev/null | grep -q '__stack_chk_fail'; then
    echo -n -e '\033[32mCanary found   \033[m   '
  else
    echo -n -e '\033[31mNo canary found\033[m   '
  fi
```

```bash title="Check the binary file - without canary" 
lazenca0x0@ubuntu:~/Documents/Definition/protection/Canary$ readelf -s ./Canary_Do-not-set |grep __stack_chk_fail
lazenca0x0@ubuntu:~/Documents/Definition/protection/Canary$
```


### Process

* **Verify whether Canary protection is enabled for a running process using the following method:**  
  + The method is similar to binary inspection, with the file path specified as /proc/<PID>/exe.
  + It additionally checks if 'Symbol table' exists in '/proc/<PID>/exe'.

```bash title="Checksec.sh - line 215"
  # check for stack canary support
  if readelf -s $1/exe 2>/dev/null | grep -q 'Symbol table'; then
    if readelf -s $1/exe 2>/dev/null | grep -q '__stack_chk_fail'; then
      echo -n -e '\033[32mCanary found         \033[m  '
    else
      echo -n -e '\033[31mNo canary found      \033[m  '
    fi
  else
    if [ "$1" != "1" ] ; then
      echo -n -e '\033[33mPermission denied    \033[m  '
    else
      echo -n -e '\033[33mNo symbol table found\033[m  '
    fi
  fi
```
