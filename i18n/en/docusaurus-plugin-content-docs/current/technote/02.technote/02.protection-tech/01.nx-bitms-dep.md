# **NX Bit(MS : DEP)**

* **What is the NX Bit (Never eXecute bit)?**
  + A CPU technology that segregates memory areas reserved for executable code instructions from those used for data storage.
  + Memory regions marked with the NX attribute are restricted to data storage, preventing processor instructions residing in those areas from being executed.
* **What is DEP (Data Execution Prevention)?**
  + A security feature included in Microsoft Windows operating systems, consisting of hardware and software technologies that perform additional memory checks to prevent malicious code from executing.
  + DEP runs in two modes:
    - Hardware-enforced DEP: Marks all memory locations in a process as non-executable unless the location explicitly contains executable code.
      * Most modern processors support hardware-enforced DEP.
    - Software-enforced DEP: Used when the CPU does not support hardware DEP.
* **For instance, for an attacker to execute shellcode stored in the Heap or Stack, that region must have execution permissions.**  
  + When DEP/NX is disabled, the shellcode executes.
  + When DEP/NX is enabled, the shellcode cannot execute because the region lacks execution permissions.
    - The program triggers an exception and terminates the process.

## **Example program**

* Compile a program containing a buffer overflow (BOF) vulnerability with stack execution permissions enabled.

```c title="Example program"
#include <stdio.h>
#include <stdlib.h>

int main(){
    char str[256];
    char *chare = (char*)malloc(100);

    printf("Input: ");
    gets(str);
    printf("%p\n", str);
}
```

```bash title="Build Command(DEP disable)"
gcc -z execstack -o DEP-disabled DEP.c
```

## **How to detect NX in the "Checksec.sh" file**

### **Binary**

* **Verify whether NX is enabled on a binary using the following method:**
  + Use the readelf command to check the segment header information of the file.
  + In the file's segment headers, if the Flg value of 'GNU_STACK' is 'RWE', NX is considered disabled; if 'RW', NX is enabled.

```bash
  # check for NX support
  if readelf -W -l $1 2>/dev/null | grep 'GNU_STACK' | grep -q 'RWE'; then
    echo -n -e '\033[31mNX disabled\033[m   '
  else
    echo -n -e '\033[32mNX enabled \033[m   '
  fi
```

* For binaries with NX enabled, the Flg value is 'RW'.
* For binaries with NX disabled, the Flg value is 'RWE'.

```bash title="NX disabled example"

lazenca0x0@ubuntu:~/Documents/Definition/protection$ readelf -W -l ./DEP-disabled |grep 'GNU_STACK' | grep 'RWE'
```

### CPU

* **Verify whether the CPU supports NX using the following method:**
  + Check for the 'nx' flag in the "/proc/cpuinfo" file.

```bash
# check cpu nx flag
nxcheck() {
  if grep -q nx /proc/cpuinfo; then
    echo -n -e '\033[32mYes\033[m\n\n'
  else
    echo -n -e '\033[31mNo\033[m\n\n'
  fi
}
```
