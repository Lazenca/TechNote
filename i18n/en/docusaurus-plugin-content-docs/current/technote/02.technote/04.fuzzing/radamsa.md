## **Description**

* Radamsa is a general-purpose data fuzzer.
  + Reads data from the specified sample file or standard input if none exists, and outputs modified data.
  + It is commonly used to generate manipulated data for program testing.
  + Supported OSs include GNU/Linux, OpenBSD, FreeBSD, Mac OS X, and Windows (using Cygwin).

### **Install**

```bash title="Install radamsa"
$ git clone https://github.com/aoh/radamsa.git ~/radamasa/
$ cd radamsa
$ make
$ sudo make install # optional, you can also just grab bin/radamsa
$ radamsa --help
```

### Command options

| Options | Description |
| --- | --- |
| -o | --output <arg>, output pattern |
| -n | --count <arg>, number of outputs to generate |
| -s | --seed <arg>, random seed (number, default random) |
| -m | --mutations <arg>, Mutations to use [ft=2,fo=2,fn,num=5,td,tr2,ts1,tr,ts2,ld,lds,lr2,li,ls,lp,lr,lis,lrs,sr,sd,bd,bf,bi,br,bp,bei,bed,ber,uw,ui=2,xp=9,ab] |
| -p | --patterns <arg>, mutation pattern to use [od,nd=2,bu] |
| -g | --generators <arg>, data generator to use [random,file=1000,jump=200,stdin=100000] |
| -M | --meta <arg>, store metadata about the generated file in this file |
| -r | --recursive, include files in subdirectories |
| -S | --seek <arg>, start with the given test case. |
| -d | --delay <arg>, wait n milliseconds between outputs |
| -l | --list, list of mutations, patterns and generators |
| -C | --checksums <arg>, maximum number of checksums in uniqueness filter (0 is disabled) [10000] |
| -v | --verbose, display progress during creation |

### **Options of Output**

| -o argument | meaning | example |
| --- | --- | --- |
| :port | * Acts as a TCP server on the designated port. | # radamsa -o :80 -n inf samples/\*.http-resp |
| ip:port | * Connect to the IP and port of the TCP client. | $ radamsa -o 127.0.0.1:80 -n inf samples/\*.http-req |
| - | * Print the results on the screen. | $ radamsa -o - samples/\*.vt100 |
| path | * Create the result as a file in the corresponding path.    + %n: test case number + %s: first suffix | $ radamsa -o test-%n.%s -n 100 samples/\*.foo |

### **Options of Mutations**

| Options of mutations | Description |
| --- | --- |
| ab | Improves silly problems when handling ASCII string data. |
| bd | drop one byte |
| bf | flip 1 bit |
| bi | Insert random bytes |
| br | repeat one byte |
| bp | change some bytes |
| bei | Increment by one byte |
| bed | Decrease by one byte |
| ber | Replace with a random byte |
| sr | Byte sequence repetition |
| sd | Delete byte sequence |
| ld | delete one line |
| lds | Delete multiple lines |
| lr2 | single line replication |
| li | Copy one nearby line |
| lr | repeat one line |
| ls | replace two lines |
| lp | Change the order of lines |
| lis | Insert a line somewhere else |
| lrs | Dating a Line Elsewhere |
| td | delete node |
| tr2 | node replication |
| ts1 | Swap one node for another |
| ts2 | swap two nodes |
| tr | Repeats the path in the parse tree. |
| uw | Try to make the code section wider |
| ui | Interesting unicode insertion |
| num | Attempt to edit text number |
| xp | Parse and transform xml |
