# Lazenca.net - Tech Note

[Lazenca.net](https://www.lazenca.net) is a comprehensive technical documentation (Tech Note) repository dedicated to system exploitation, reverse engineering, vulnerability research, and software security engineering.

Built with [Docusaurus](https://docusaurus.io/), this project serves as a structured knowledge base, continuously updated with in-depth research articles, analysis techniques, and practical guides.

---

## 📚 Topics & Contents

This repository covers a wide spectrum of system security topics:

- **Analysis & Tools**: Binary analysis, debugging tools, and reverse engineering methodologies
- **Protection Tech**: In-depth analysis of modern OS and compiler-level memory mitigation/protection mechanisms
- **Fuzzing**: Automated vulnerability discovery, fuzzing techniques, and tooling
- **Basic Exploitation**: Fundamental exploit techniques including Stack Buffer Overflows, Format String Bugs, etc.
- **Heap Exploitation**: glibc heap internals and advanced version-specific heap exploit techniques
- **Linux Kernel Exploitation**: Linux kernel vulnerability analysis and privilege escalation techniques
- **Game Security**: Game security mechanisms, anti-debugging, and reverse analysis
- **Security Coding & References**: Secure development practices, reference tables, and security guidelines
