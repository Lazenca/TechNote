# **ASLR**

* **What is ASLR (Address Space Layout Randomization)?**
  + A security technique designed to prevent memory corruption exploitation.
  + Randomizes the locations of the stack, heap, libraries, etc. in memory, making it difficult for an attacker to predict target addresses needed for exploitation.
  + The base addresses change every time the program executes.
* **For example, to perform a Return-to-libc (RTL) attack, the attacker must know the address of target functions in shared libraries.**
  + If these address values are fixed across executions, exploitation is straightforward.
  + However, with ASLR enabled, the addresses of the stack, heap, and library regions change on each execution, significantly complicating exploitation (though not making it entirely impossible).

## **Set ASLR**

:::note[cmd]
echo 0 > /proc/sys/kernel/randomize\_va\_space
:::

:::note[option]
0 : Disable ASLR  
1 : Randomize stack and mmap/libraries  
2 : Randomize stack, mmap/libraries, and heap (brk)
:::

## **Example**

### Source code

* **The code below performs the following operations:**
  + Prints the addresses of heap, stack, libc, and .data.

```c title="Example Source code"
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

char *global = "Lazenca.0x0";
 
int main(){
	char *heap = malloc(100);
	char *stack[] = {"LAZENCA.0x0"};

	printf("[Heap]  addresss: %p\n", heap);
	printf("[Stack] addresss: %p\n", stack);
	printf("[libc]  addresss: %p\n",**(&stack + 3));
	printf("[.data] addresss: %p\n",global);
	gets(heap);
	return 0;
}
```

## **How to detect ASLR in the "Checksec.sh" file**

* **Verify the system-wide ASLR setting using the following method:**
  + Search for 'PaX:' in the "/proc/1/status" file and check if 'R' is present in the output.
    - If all conditions are met, it is determined as "PaX ASLR enabled".
  + If 'PaX' is not present in "/proc/1/status", check via the 'sysctl' command.
    - Determine the ASLR configuration by checking the value of "kernel.randomize_va_space =" returned by 'sysctl'.

```bash title="Checksec.sh" showLineNumbers={285}
# check for system-wide ASLR support
aslrcheck() {
  # PaX ASLR support
  if !(cat /proc/1/status 2> /dev/null | grep -q 'Name:') ; then
    echo -n -e ':\033[33m insufficient privileges for PaX ASLR checks\033[m\n'
    echo -n -e '  Fallback to standard Linux ASLR check'
  fi
  
  if cat /proc/1/status 2> /dev/null | grep -q 'PaX:'; then
    printf ": "
    if cat /proc/1/status 2> /dev/null | grep 'PaX:' | grep -q 'R'; then
      echo -n -e '\033[32mPaX ASLR enabled\033[m\n\n'
    else
      echo -n -e '\033[31mPaX ASLR disabled\033[m\n\n'
    fi
  else
    # standard Linux 'kernel.randomize_va_space' ASLR support
    # (see the kernel file 'Documentation/sysctl/kernel.txt' for a detailed description)
    printf " (kernel.randomize_va_space): "
    if /sbin/sysctl -a 2>/dev/null | grep -q 'kernel.randomize_va_space = 1'; then
      echo -n -e '\033[33mOn (Setting: 1)\033[m\n\n'
      printf "  Description - Make the addressses of mmap base, stack and VDSO page randomized.\n"
      printf "  This, among other things, implies that shared libraries will be loaded to \n"
      printf "  random addressses. Also for PIE-linked binaries, the location of code start\n"
      printf "  is randomized. Heap addressses are *not* randomized.\n\n"
    elif /sbin/sysctl -a 2>/dev/null | grep -q 'kernel.randomize_va_space = 2'; then
      echo -n -e '\033[32mOn (Setting: 2)\033[m\n\n'
      printf "  Description - Make the addressses of mmap base, heap, stack and VDSO page randomized.\n"
      printf "  This, among other things, implies that shared libraries will be loaded to random \n"
      printf "  addressses. Also for PIE-linked binaries, the location of code start is randomized.\n\n"
    elif /sbin/sysctl -a 2>/dev/null | grep -q 'kernel.randomize_va_space = 0'; then
      echo -n -e '\033[31mOff (Setting: 0)\033[m\n'
    else
      echo -n -e '\033[31mNot supported\033[m\n'
    fi
    printf "  See the kernel file 'Documentation/sysctl/kernel.txt' for more details.\n\n"
  fi 
}
```

* **First, check the ASLR setting via the "/proc/1/status" file.**
  + However, on this standard Linux distribution without PaX, ASLR status cannot be determined via "/proc/1/status".
  + This is because "PaX" information is not present in the status file.
* **Therefore, you can check the ASLR setting using the 'sysctl' command as shown below:**
  + The setting value on this system is '2'.
