# **PIE(Position Independent Executable)**

## **Description**

* PIE (Position Independent Executable) is an executable binary composed entirely of position-independent code.

## **Example**

### **Source code**

```c
#include <stdio.h>
 
char *gBuf = "Lazenca.0x0";
 
void lazenca() {
	printf("Lazenca.0x1\n");
}
 
void main(){
	printf("[.data]    : %p\n",gBuf);
	printf("[Function] : %p\n",lazenca);
}
```

### Build PIE file

```bash title="Build"
lazenca0x0@ubuntu:~/Documents/Definition/protection/PIE$ gcc -o NoPIE PIE.c 
lazenca0x0@ubuntu:~/Documents/Definition/protection/PIE$ gcc -fPIE -pie -o PIE PIE.c
```

### Code

* **The differences between binaries with and without PIE can be observed as follows:**
  + In a non-PIE binary, the instruction addresses in the disassembly are fixed absolute virtual addresses (e.g. 0x400577).
  + In contrast, in a PIE binary, the code addresses in the file are relative offsets (e.g. 0x7c3).
    - Using these offsets, the binary can be dynamically mapped to any randomized base address in memory.
  + Address calculation occurs dynamically at runtime:
    - Allocated base memory region (0x555555554000) + offset of main in .text (0x7c3) = runtime entry address of main (0x00005555555547c3).

## **How to detect PIE in the "Checksec.sh" file**

### Binary

* **Verify whether PIE is enabled in a binary using the following method:**
  + Inspect the ELF Header using readelf to determine PIE configuration.
  + If the "Type:" field is "EXEC", PIE is disabled ("No PIE").
  + If the "Type:" field is "DYN", the file is position-independent.
    - Inspect the Dynamic section via readelf; if a `(DEBUG)` tag exists, PIE is enabled ("PIE enabled"), otherwise it is classified as a DSO ("DSO").

```bash title="Checksec.sh - line 170" 
  # check for PIE support
  if readelf -h $1 2>/dev/null | grep -q 'Type:[[:space:]]*EXEC'; then
    echo -n -e '\033[31mNo PIE       \033[m   '
  elif readelf -h $1 2>/dev/null | grep -q 'Type:[[:space:]]*DYN'; then
    if readelf -d $1 2>/dev/null | grep -q '(DEBUG)'; then
      echo -n -e '\033[32mPIE enabled  \033[m   '
    else   
      echo -n -e '\033[33mDSO          \033[m   '
    fi
  else
    echo -n -e '\033[33mNot an ELF file\033[m   '
  fi
```

```bash title="readelf -h ./NoPIE"
lazenca0x0@ubuntu:~/Documents/Definition/protection/PIE$ readelf -h ./NoPIE |grep 'Type:[[:space:]]*EXEC'
  Type:                              EXEC (Executable file)
lazenca0x0@ubuntu:~/Documents/Definition/protection/PIE$
```

```bash title="readelf -h ./PIE"    
lazenca0x0@ubuntu:~/Documents/Definition/protection/PIE$ readelf -h ./PIE |grep 'Type:[[:space:]]*DYN'
  Type:                              DYN (Shared object file)
lazenca0x0@ubuntu:~/Documents/Definition/protection/PIE$ readelf -d ./PIE |grep '(DEBUG)'
 0x0000000000000015 (DEBUG)              0x0
lazenca0x0@ubuntu:~/Documents/Definition/protection/PIE$
```

### Process

* **Verify whether PIE is enabled for a running process using the following method:**  
  + Similar to binary inspection, with the file path specified as:
    - Ex) /proc/<PID>/exe

```bash title="Checksec.sh - line 256" 
  # check for PIE support
  if readelf -h $1/exe 2>/dev/null | grep -q 'Type:[[:space:]]*EXEC'; then
    echo -n -e '\033[31mNo PIE               \033[m   '
  elif readelf -h $1/exe 2>/dev/null | grep -q 'Type:[[:space:]]*DYN'; then
    if readelf -d $1/exe 2>/dev/null | grep -q '(DEBUG)'; then
      echo -n -e '\033[32mPIE enabled          \033[m   '
    else   
      echo -n -e '\033[33mDynamic Shared Object\033[m   '
    fi
  else
    echo -n -e '\033[33mNot an ELF file      \033[m   '
  fi
```
