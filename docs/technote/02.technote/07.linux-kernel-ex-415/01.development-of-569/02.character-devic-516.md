## **Character Device Drivers**

* **A Character Device driver is a driver that reads and writes data one character (byte) at a time without using a buffer cache.**
  + Examples: Keyboard, Sound card, Printer drivers
* **In addition, there are Block Device and Network Device drivers.**  
  + Block device drivers allow random access and perform I/O in blocks via a buffer cache.
    - Example: Hard drives
  + Network device drivers reside between the network stack and the network hardware to handle sending and receiving data.  
    - Examples: Ethernet, Network Interface Cards (NICs)

### **struct file_operations**

* **The `file_operations` structure provides the interface for communication between character/block device drivers and user space programs.**
  + It holds function pointers such as `read`, `write`, `open`, `release`, `unlocked_ioctl`, etc.
  + Network devices do not use the `file_operations` structure.
    - They use `struct net_device` defined in `include/linux/netdevice.h`.

	int (*iterate) (struct file *, struct dir_context *);

	int (*flush) (struct file *, fl_owner_t id);

    - The function is named `chardev_open`, and when called, it outputs "chardev_open" as a kernel message.
  + Assign the function address (`chardev_open`) to the `.open` field of the `struct file_operations` structure instance.

### Source code

* **This code operates as follows:**
  + When the device module is loaded into the kernel, `chardev_init()` is executed.
    - Inside this function, `register_chrdev()` registers the character device's major number.
  + When user space opens the device, `chardev_open()` is invoked.
  + When the device module is removed from the kernel, `chardev_exit()` is executed.  
    - Inside this function, `unregister_chrdev()` unregisters the character device's major number.

```c title="chardev.c"
#include <linux/init.h>
#include <linux/module.h>
#include <linux/types.h>
#include <linux/kernel.h>
#include <linux/fs.h>
#include <linux/cdev.h>
#include <linux/sched.h>
#include <linux/device.h>
#include <linux/slab.h>
#include <asm/current.h>
#include <linux/uaccess.h>

#define DEVICE_NAME "chardev"
#define DEVICE_FILE_NAME "chardev"
#define MAJOR_NUM 100

static int chardev_open(struct inode *inode, struct file *file)
{
	printk("chardev_open");
	return 0;
}

struct file_operations chardev_fops = {
	.open    = chardev_open,
};

static int chardev_init(void)
{
	int ret_val;
	ret_val = register_chrdev(MAJOR_NUM, DEVICE_NAME, &chardev_fops);

	if (ret_val < 0) {
	printk(KERN_ALERT "%s failed with %d\n",
	       "Sorry, registering the character device ", ret_val);
	return ret_val;
	}

	printk(KERN_INFO "%s The major device number is %d.\n",
	   "Registeration is a success", MAJOR_NUM);
	printk(KERN_INFO "If you want to talk to the device driver,\n");
	printk(KERN_INFO "you'll have to create a device file. \n");
	printk(KERN_INFO "We suggest you use:\n");
	printk(KERN_INFO "mknod %s c %d 0\n", DEVICE_FILE_NAME, MAJOR_NUM);
	printk(KERN_INFO "The device file name is important, because\n");
	printk(KERN_INFO "the ioctl program assumes that's the\n");
	printk(KERN_INFO "file you'll use.\n");

	return 0;
}

static void chardev_exit(void)
{
	unregister_chrdev(MAJOR_NUM, DEVICE_NAME);
}

module_init(chardev_init);
module_exit(chardev_exit);
```

## **Example [struct file_operations.open, .release, .read, .write]**

### **Source code**

#### **chardev_init()**

* **When the module is loaded into the kernel, `chardev_init()` performs the following:**
  + Registers a character device region in the system using `alloc_chrdev_region()`.
  + Retrieves the Major and Minor numbers using `MAJOR()` and `MKDEV()`.
  + Initializes the `chardev_cdev` structure using `cdev_init()`.
  + Adds the character device to the system using `cdev_add()`.
  + Creates a device class in the system using `class_create()`.
  + Creates device nodes in the system using `device_create()`.

#### **chardev_exit()**

* **When the module is unloaded from the kernel, `chardev_exit()` performs the following:**
  + Destroys the devices created by `device_create()` using `device_destroy()`.
  + Destroys the device class created by `class_create()` using `class_destroy()`.
  + Removes the character device added by `cdev_add()` using `cdev_del()`.
  + Frees the registered device numbers allocated by `alloc_chrdev_region()` using `unregister_chrdev_region()`.

#### **chardev_open()**

* **Whenever user space opens the device, `chardev_open()` is called and performs the following:**
  + Allocates memory for `struct data` in the kernel heap using `kmalloc()`.
  + Copies the string stored in the `str` variable into the `p->buffer` area using `strlcpy()`.

#### **chardev_release()**

* **When user space closes the device, `chardev_release()` is called and performs the following:**
  + Frees the allocated kernel heap memory using `kfree()`.

#### **chardev_write()**

* **When data is sent to the device from user space, `chardev_write()` is called and performs the following:**
  + Copies data passed from user space (`buf`) into `p->buffer` using `copy_from_user()`.

#### **chardev_read()**

* **When data is requested from the device by user space, `chardev_read()` is called and performs the following:**
  + Copies the `p->buffer` data stored in kernel space into the user space `buf` variable using `copy_to_user()`.

```c title="chardev.c"
#include <linux/init.h>
#include <linux/module.h>
#include <linux/types.h>
#include <linux/kernel.h>
#include <linux/fs.h>
#include <linux/cdev.h>
#include <linux/sched.h>
#include <linux/device.h>
#include <linux/slab.h>
#include <asm/current.h>
#include <linux/uaccess.h>

MODULE_LICENSE("Dual BSD/GPL");

#define DRIVER_NAME "chardev"
#define BUFFER_SIZE 256
	
static const unsigned int MINOR_BASE = 0;
static const unsigned int MINOR_NUM  = 2;
static unsigned int chardev_major;
static struct cdev chardev_cdev;
static struct class *chardev_class = NULL;

static int     chardev_open(struct inode *, struct file *);
static int     chardev_release(struct inode *, struct file *);
static ssize_t chardev_read(struct file *, char *, size_t, loff_t *);
static ssize_t chardev_write(struct file *, const char *, size_t, loff_t *);

struct file_operations chardev_fops = {
	.open    = chardev_open,
	.release = chardev_release,
	.read    = chardev_read,
	.write   = chardev_write,
};

struct data {
	unsigned char buffer[BUFFER_SIZE];
};

static int chardev_init(void)
{
	int alloc_ret = 0;
	int cdev_err = 0;
	int minor;
	dev_t dev;

	printk("The chardev_init() function has been called.");
	
	alloc_ret = alloc_chrdev_region(&dev, MINOR_BASE, MINOR_NUM, DRIVER_NAME);
	if (alloc_ret != 0) {
		printk(KERN_ERR  "alloc_chrdev_region = %d\n", alloc_ret);
		return -1;
	}
	//Get the major number value in dev.
	chardev_major = MAJOR(dev);
	dev = MKDEV(chardev_major, MINOR_BASE);

	//initialize a cdev structure
	cdev_init(&chardev_cdev, &chardev_fops);
	chardev_cdev.owner = THIS_MODULE;

	//add a char device to the system
	cdev_err = cdev_add(&chardev_cdev, dev, MINOR_NUM);
	if (cdev_err != 0) {
		printk(KERN_ERR  "cdev_add = %d\n", alloc_ret);
		unregister_chrdev_region(dev, MINOR_NUM);
		return -1;
	}

	chardev_class = class_create(THIS_MODULE, "chardev");
	if (IS_ERR(chardev_class)) {
		printk(KERN_ERR  "class_create\n");
		cdev_del(&chardev_cdev);
		unregister_chrdev_region(dev, MINOR_NUM);
		return -1;
	}

	for (minor = MINOR_BASE; minor < MINOR_BASE + MINOR_NUM; minor++) {
		device_create(chardev_class, NULL, MKDEV(chardev_major, minor), NULL, "chardev%d", minor);
	}

	return 0;
}

static void chardev_exit(void)
{
	int minor;	
	dev_t dev = MKDEV(chardev_major, MINOR_BASE);
	
	printk("The chardev_exit() function has been called.");
	
	for (minor = MINOR_BASE; minor < MINOR_BASE + MINOR_NUM; minor++) {
		device_destroy(chardev_class, MKDEV(chardev_major, minor));
	}

	class_destroy(chardev_class);
	cdev_del(&chardev_cdev);
	unregister_chrdev_region(dev, MINOR_NUM);
}

static int chardev_open(struct inode *inode, struct file *file)
{
	char *str = "helloworld";
	int ret;

	struct data *p = kmalloc(sizeof(struct data), GFP_KERNEL);

	printk("The chardev_open() function has been called.");
	
	if (p == NULL) {
		printk(KERN_ERR  "kmalloc - Null");
		return -ENOMEM;
	}

	ret = strlcpy(p->buffer, str, sizeof(p->buffer));
	if(ret > strlen(str)){
		printk(KERN_ERR "strlcpy - too long (%d)",ret);
	}

	file->private_data = p;
	return 0;
}

static int chardev_release(struct inode *inode, struct file *file)
{
	printk("The chardev_release() function has been called.");
	if (file->private_data) {
		kfree(file->private_data);
		file->private_data = NULL;
	}
	return 0;
}

static ssize_t chardev_write(struct file *filp, const char __user *buf, size_t count, loff_t *f_pos)
{
	struct data *p = filp->private_data;

	printk("The chardev_write() function has been called.");	
	printk("Before calling the copy_from_user() function : %p, %s",p->buffer,p->buffer);
	if (copy_from_user(p->buffer, buf, count) != 0) {
		return -EFAULT;
	}
	printk("After calling the copy_from_user() function : %p, %s",p->buffer,p->buffer);
	return count;
}

static ssize_t chardev_read(struct file *filp, char __user *buf, size_t count, loff_t *f_pos)
{
	struct data *p = filp->private_data;

	printk("The chardev_read() function has been called.");
	
	if(count > BUFFER_SIZE){
		count = BUFFER_SIZE;
	}

	if (copy_to_user(buf, p->buffer, count) != 0) {
		return -EFAULT;
	}

	return count;
}

module_init(chardev_init);
module_exit(chardev_exit);
```
