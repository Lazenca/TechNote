
### Simple Linux Kernel Module

* **The following code is the simplest Kernel Module code.**
  + The `init_module()` function contains the code executed when the module is inserted into the kernel.
  + The `cleanup_module()` function contains the code executed when the module is removed from the kernel.
  + In this code, `printk()` is used to print messages when the module is inserted and removed.

```c title="sample.c"
#include <linux/module.h> /* Needed by all modules */
#include <linux/kernel.h> /* Needed for KERN_INFO */

int init_module(void) { 
	printk(KERN_INFO "Hello world - Lazenca0x0.\n");
	return 0;
}

void cleanup_module(void) { 
	printk(KERN_INFO "Goodbye world - Lazenca0x0.\n");
}
```

* **You can build the module using the following Makefile.**

```makefile title="Makefile"
obj-m += sample.o

all:
	make -C /lib/modules/$(shell uname -r)/build M=$(PWD) modules

clean:
	make -C /lib/modules/$(shell uname -r)/build M=$(PWD) clean
```

  + Kernel module : sample.ko

### insmod - simple program to insert a module into the Linux Kernel

* **The `insmod` command can be used to insert a module into the Linux kernel.**
* **The `lsmod` command can be used to check modules loaded in the Linux kernel.**

```sh title="Insert the Kernel Module"
lazenca0x0@ubuntu:~/Kernel/Module$ sudo insmod ./sample.ko 
lazenca0x0@ubuntu:~/Kernel/Module$ lsmod | grep sample
sample                 16384  0
lazenca0x0@ubuntu:~/Kernel/Module$
```

* **The `dmesg` command can be used to view the messages output by the module.**
  + After "sample.ko" module was inserted into the kernel, the "Hello world - Lazenca0x0." message was printed.
